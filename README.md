# Homework 16.1

Домашнее задание по ООП: наследование. Проект «Электронный магазин».

## Описание

- `Product` — базовый класс товара (название, описание, приватная цена, количество).
- `Smartphone` — класс-наследник товара: смартфон. Расширен атрибутами:
  - `efficiency` — производительность;
  - `model` — модель;
  - `memory` — объём встроенной памяти;
  - `color` — цвет.
- `LawnGrass` — класс-наследник товара: трава газонная. Расширен атрибутами:
  - `country` — страна-производитель;
  - `germination_period` — срок прорастания;
  - `color` — цвет.
- `Category` — категория товаров со счётчиками категорий и товаров,
  итератором и защищённым добавлением товара.
- `CategoryIterator` — итератор по товарам категории.

## Что нового в этой домашке

- Классы `Smartphone` и `LawnGrass` созданы наследованием от `Product`.
  Общие атрибуты инициализируются в родителе через `super().__init__`,
  специфичные — в дочерних классах.
- Сложение товаров (`__add__`) ограничено: складывать можно только объекты
  одного класса. Проверка выполняется через `type()`: попытка сложить
  смартфон и траву газонную вызывает `TypeError`.
- Метод `Category.add_product` защищён проверкой `isinstance(product, Product)`:
  в категорию можно добавлять только `Product` и его наследников, любой другой
  объект вызывает `TypeError`.
- Написаны тесты для новой функциональности: атрибуты наследников, проверки
  `isinstance` и `issubclass`, унаследованный `__str__`, сложение однотипных
  товаров, ошибки `TypeError` при разных классах и при добавлении не-продукта.
- Удалён устаревший тестовый модуль `tests/test_main.py`, импортировавший
  классы из `main.py` (классы переехали в `src` в предыдущих домашках).
