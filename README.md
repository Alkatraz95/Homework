# Homework 15.1

Домашнее задание по ООП: классы `Product` и `Category` с магическими методами.

## Описание

- `Product` — товар магазина (название, описание, цена, количество).
- `Category` — категория товаров со счётчиками категорий и товаров.

В этой версии реализованы приватные атрибуты, property, класс-метод
и магические методы:

- `Product`:
  - приватная цена `__price` с геттером и сеттером;
  - сеттер не принимает нулевую и отрицательную цену — выводит сообщение
    «Цена не должна быть нулевая или отрицательная» и оставляет прежнее значение;
  - класс-метод `new_product` — создаёт товар из словаря с параметрами;
  - метод `__str__` — строковое представление вида
    «Название продукта, цена руб. Остаток: N шт.»;
  - метод `__add__` — складывает два товара: возвращает полную стоимость
    товаров на складе (цена × количество для каждого из товаров);
- `Category`:
  - приватный список товаров `__products` (доступ только через методы и геттер);
  - метод `add_product` — добавляет товар в категорию и увеличивает счётчик продуктов;
  - метод `__str__` — строковое представление вида
    «Название категории, количество продуктов: N шт.», где N — общее
    количество товаров на складе;
  - геттер `products` возвращает строку-список товаров, используя
    строковое представление каждого продукта;
  - метод `__iter__` — возвращает итератор по товарам категории;
- `CategoryIterator` — вспомогательный класс-итератор: перебирает товары
  одной категории (можно использовать, например, в цикле for).

Счётчики `category_count` и `product_count` — класс-атрибуты, ведут общую
статистику по всем созданным категориям и товарам.
